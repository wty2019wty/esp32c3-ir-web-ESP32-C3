WiFi 设置

修改后点击"保存并重启"：设备 2 秒后自动重启应用新配置，请稍候 10-20 秒重新连接。
工作模式自动互斥：配置了"连接 WiFi"则设备只连接路由器（不开热点；连接失败超时后降级开热点兜底）；"连接 WiFi"留空则设备只开启热点。

服务模式

取消勾选后，设备重启将停止提供内置 Web 页面， 只保留 ws://<IP>/api/ws 供外部前端连接 （前后端分离场景）。保存后设备 2 秒自动重启生效，请用外部前端继续访问。

Web 登录

默认 admin / admin，首次登录会强制修改。修改后需用新账号重新登录。

登录

请先填写设备 WebSocket 地址（支持 ws:// 或 wss://），再输入账号密码连接。
